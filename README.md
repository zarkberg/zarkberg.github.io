# 专利雷达｜技术机会助手

**从一个技术痛点，找到下一步。**

在线体验：<https://zarkberg.github.io/>

专利雷达面向创业者、产品经理、研发人员和专利申请人，将技术痛点转化为可理解的专利证据、技术路线和下一步行动建议。

## 现在可以体验什么

当前在线版本以“智能养老设备：老人跌倒检测”为示例，支持：

- 输入技术痛点并获得结构化拆解；
- 查看技术路线、趋势和代表性专利；
- 阅读机会与风险提示；
- 查看专利权人、院校院所和企业线索；
- 模拟深度报告解锁与付费咨询；
- 收藏项目、复制分享文案和生成报告入口。

## 参与试用

请用一个真实但**不包含商业秘密或未公开发明细节**的技术问题体验，例如：

> 想做一种适合独居老人的居家跌倒检测设备，降低误报并保护隐私。

体验后请告诉我们：

1. 你属于创业者、产品经理、研发人员、专利申请人还是其他用户；
2. 哪个结果最有帮助；
3. 哪个结果不准确或难以理解；
4. 你愿意为报告、监控或咨询中的哪项功能付费。

## 反馈入口

- 产品体验和功能建议：<https://github.com/zarkberg/zarkberg.github.io/discussions>
- Bug 或页面问题：<https://github.com/zarkberg/zarkberg.github.io/issues/new/choose>
- 在线体验：<https://zarkberg.github.io/>

请勿在公开 Issue 或 Discussion 中提交未公开技术方案、商业秘密、个人敏感信息或尚未申请专利的完整发明内容。

## 当前限制

- 当前页面使用演示样例数据，不代表完整专利数据库；
- 正式版本需要接入合法授权或开放数据源；
- 法律状态应以官方登记信息为准；
- AI 分析仅供技术学习和初步检索参考，不构成专利代理、侵权判断、投资或法律意见；
- 当前支付、咨询和报告下载为体验流程，不代表已提供实际服务。
