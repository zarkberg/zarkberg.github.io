# 专利雷达｜技术机会助手

**从一个技术痛点，找到下一步。**

在线体验：<https://zarkberg.github.io/>

专利雷达面向创业者、产品经理、研发人员和专利申请人，将技术痛点转化为可理解的专利证据、技术路线和下一步行动建议。

## 现在可以体验什么

当前在线版本以“智能养老设备：老人跌倒检测”为示例，支持：

- 输入技术痛点并获得结构化拆解；
- 查看技术路线、趋势和代表性专利；
- 阅读机会与风险提示；
- 查看专利权人、院校院所和企业线索；
- 模拟深度报告解锁与付费咨询；
- 收藏项目、复制分享文案和生成报告入口。

## 参与试用

请用一个真实但**不包含商业秘密或未公开发明细节**的技术问题体验，例如：

> 想做一种适合独居老人的居家跌倒检测设备，降低误报并保护隐私。

体验后请告诉我们：

1. 你属于创业者、产品经理、研发人员、专利申请人还是其他用户；
2. 哪个结果最有帮助；
3. 哪个结果不准确或难以理解；
4. 你愿意为报告、监控或咨询中的哪项功能付费。

## 当前限制

- 农产品商情匹配 MVP 只接收用户主动粘贴、转发、截图识别或授权导入的内容，不读取个人朋友圈或监听微信群；
- 来源链记录的是授权来源类型和脱敏标签，不公开完整社交关系；联系方式交换需对方确认；
- 当前商情匹配、来源网络、联系申请和收费流程均为本地演示，不代表真实支付、担保或成交；
- 当前页面使用演示样例数据，不代表完整专利数据库；
- 正式版本需要接入合法授权或开放数据源；
- 法律状态应以官方登记信息为准；
- AI 分析仅供技术学习和初步检索参考，不构成专利代理、侵权判断、投资或法律意见；
- 当前支付、咨询和报告下载为体验流程，不代表已提供实际服务。

## 农产品商情匹配 MVP

小程序测试页支持“我有货/我要采购”、群消息结构化识别、来源授权确认、群主协作入口、模拟匹配和联系申请。

产品原则：

- 先做商情基础设施，再逐步做交易撮合；
- 来源可追溯，但只保留最小必要的授权来源信息；
- 联系方式交换前展示信任提示，并由双方确认；
- 正式收费应使用透明的信息服务费，自愿打赏不能作为强制交换联系方式的前置条件；
- 平台早期不经手货款、不承诺成交、不提供交易担保。

微信开发者工具导入目录：`eldercare-miniprogram/`。正式部署前仍需配置真实 AppID、HTTPS API、隐私政策、合法数据域名和后端数据库。
