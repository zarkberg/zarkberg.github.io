# 农产品商情匹配 MVP

这是与“专利雷达｜技术机会助手”完全独立的产品 MVP，面向微信群和朋友圈场景中的农产品供需信息整理与匹配。

## MVP 能力

- 主动粘贴群消息并识别品类、数量、地区和时间；
- 记录用户确认过的授权来源类型和脱敏来源标签；
- 生成群主/组织协作入口；
- 模拟供需匹配并展示匹配理由；
- 联系申请先取得对方确认，不直接公开联系方式。

## 合规边界

本 MVP 不读取个人朋友圈、不监听微信群、不抓取联系人关系。用户只能主动提交本人有权分享的信息。正式版应使用透明的信息服务费；自愿打赏不能作为交换联系方式的强制前置条件。平台早期不经手货款、不承诺成交、不提供交易担保。

## 微信开发者工具

导入目录：`eldercare-miniprogram/`。

正式部署前仍需配置真实 AppID、HTTPS API、隐私政策、合法数据域名和后端数据库。
